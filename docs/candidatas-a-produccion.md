# Candidatas a producción

Lecciones aprobadas en este repo que corrigen una pieza del **harness de producción**: escéptico, reflector, `ticket-loop`, hooks o CLI.

Este repo nunca modifica `~/.claude/` ni `C:\AZZULE\IA harness`. Por eso estas lecciones no se aplican aquí. Quedan anotadas con su evidencia, y el desarrollador decide después si las lleva a `C:\AZZULE\IA harness`, con su propia prueba.

Las lecciones que corrigen piezas de este repo (`rules.json`, checks, `agent-dotnet-api`, el skill del puente) no van aquí: se aplican directamente.
